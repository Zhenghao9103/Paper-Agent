# 程序性记忆

## Purpose

让 Paper-Agent 从有结果可核查的交互中提取可复用的执行策略，在同一用户的新会话中按相关性召回，并使策略来源、更新、实际使用及失效过程可追踪。

## ADDED Requirements

### Requirement: R1 有证据的经验提取
ACE 反思 MUST 由已落库的用户纠正、明确反馈或有可验证结果的执行事件触发。候选必须引用来源并描述可迁移的操作。

#### Scenario: 用户纠正讲解顺序
- **WHEN** 用户在一次数学讲解后明确要求先举例再解释公式
- **THEN** 反思可提出带来源、适用条件和有序步骤的教学策略。

#### Scenario: 普通聊天
- **WHEN** 只有事实陈述、一次问候或模型自评成功
- **THEN** 跳过程序性写入，且无触发事件时不调用反思模型。

### Requirement: R2 Skill 与增量反馈
Harness MUST 校验稳定 ID、触发条件、策略步骤、约束、来源事件、反馈、版本和启用状态。Judge 可建议新增、修订、停用或跳过，持久化由 Harness 裁决。

#### Scenario: 有效修订
- **WHEN** 新反馈指向现有策略并细化其适用条件
- **THEN** 保留 ID，递增版本，保存反馈来源；明确否定该策略时可停用并追溯原因。

#### Scenario: 候选无效
- **WHEN** 步骤为空、来源不存在或修订目标不存在
- **THEN** 拒绝候选并记录原因，已有版本保持有效。

### Requirement: R3 写入和恢复
系统 MUST 以来源事件和目标操作去重，原子提交 Skill 变更与待同步记录，并串行化同一 Skill 的版本更新。

#### Scenario: 重复或并发
- **WHEN** 同一反馈重放两次，或两个不同反馈同时修改同一版本
- **THEN** 同一反馈只计一次，竞争写入重新读取最新版本再判断，不能覆盖已提交反馈。

#### Scenario: 索引服务中断
- **WHEN** 数据库提交后进程退出或外部索引失败
- **THEN** 重启后重放待同步操作；成功才确认同步，原对话可正常结束。

### Requirement: R4 本地两阶段检索
RSI MUST 在本地实例的共享 Skill 库内按相似度在线归簇，检索最多三个相关簇，再从候选中返回最多四条去重的有效 Skill；空库和无相关候选均允许零命中。

#### Scenario: 库持续增长
- **WHEN** 新增向量达到配置的归簇阈值，或所有现有簇均低于阈值
- **THEN** 分别加入最佳簇并更新中心，或建立新簇；查询只访问选中簇的成员。

#### Scenario: 空库或低相关
- **WHEN** 本地库为空，或所有候选均低于召回阈值
- **THEN** 均不注入；排序并列使用稳定 ID 决定次序。

### Requirement: R5 索引生命周期
关系库 MUST 决定版本和可用性。查询必须过滤过期、停用、已删除及重复成员。

#### Scenario: 追加索引残留旧向量
- **WHEN** 更新改变 Skill 所属簇或用户撤销 Skill 后，旧向量仍被召回
- **THEN** 旧版本立即不可见；同步完成后仅当前有效版本参与排序与簇统计。

#### Scenario: 索引丢失
- **WHEN** 从持久库在相同配置和稳定顺序下重建
- **THEN** 恢复全部有效版本；构建失败时切换至当前有效数据的平面检索，记录降级。

### Requirement: R6 普通问答消费策略
Generator MUST 在独立的、有长度上限的策略区接收已筛选 Skill。当前用户指令、权限与事实证据规则优先。

#### Scenario: 跨会话普通问答
- **WHEN** 同一用户在新会话请求讲解新概念，召回先举例的策略
- **THEN** 真实普通问答入口将策略传入模型请求；受控端到端样例先给实例，再解释定义，可追踪实际注入 ID 与版本。

#### Scenario: 指令冲突或预算不足
- **WHEN** 用户要求只给公式，或下一条完整策略超出预算
- **THEN** 冲突策略不影响用户要求；装配时跳过放不下的策略。空结果走现有回答路径，Skill 不能作为论文证据或授权工具执行。

### Requirement: R7 对照实验与回归
评估 MUST 在固定普通对话任务、相同模型设置、相同历史顺序和预先定义的评分规则上运行四个条件，并保留逐例记录。

#### Scenario: 比较写入与读取
- **WHEN** 依次运行 V2、ACE 仅写、ACE 加平面检索、ACE 加 RSI
- **THEN** 仅写组核验提取质量；两种检索共享同一 Skill 快照、向量模型与注入预算。报告策略命中、任务达成、延迟及注入 token，逐例注明失败和降级。

#### Scenario: 关闭功能或升级旧库
- **WHEN** 以已有 V2 数据升级并关闭 V3 后运行普通问答、论文问答和记忆回归
- **THEN** V2 数据仍可读写，普通问答无策略注入，论文证据与引用规则通过原有回归。
