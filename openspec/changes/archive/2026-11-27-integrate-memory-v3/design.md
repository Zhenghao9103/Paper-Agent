# Design

## Context

本地 `faea50b` 在主线 `302cafb` 上增加程序记忆。与独立 RSI 的 `75432f6` 对比，聚类检索逻辑一致，写入模块的差异集中在宿主依赖。V2 语义写入已有会话来源，部分路径有 checkpoint；程序记忆已有来源消息和反馈记录。

## Goals / Non-Goals

本次以派生记忆能定位具体来源作为情景保留的验收边界。聊天历史沿用现有持久化策略；历史事件搜索、旧聊天批量提炼及自动清理策略均在本次范围之外。

## Decisions

- 沿用应用内的 RSI 实现，共用会话、事务、模型配置及迁移。直接使用独立包的高层 Memory API 会引入另一套会话和回答流程。后续同步 RSI 改动时，以对应上游版本作比对。
- 优先引用已有消息、反馈或 checkpoint。显式语义写入若只能指向会话，补足具体消息引用。对发生写入或修订的来源保留足够上下文；语义提炼与策略反思分别裁决是否采纳，一次交互可支持其中一种或两种。
- 提议新安装默认开启 RSI；显式设置 off、write、flat、rsi 优先。现有 procedural-memory 规格继续约束降级、去重、上下文预算与策略使用记录。

## Risks / Trade-offs

启用后，符合条件的反馈会产生额外模型调用。配置说明应写明如何切换模式。历史记录缺少具体来源时保留原始资料，新写入才适用细粒度追溯要求。

## Migration Plan

用 2.2 数据库副本验证升级至最新 Alembic 版本及原有记忆召回。升级前备份，回退部署时恢复匹配版本的备份。
