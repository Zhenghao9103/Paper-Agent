# episodic-grounding Specification

## Purpose

情景记忆为语义记忆与程序记忆提供具体交互依据。用户表达的稳定偏好或反馈中可复用的做法可以分别保留，后续检查时能定位产生这条记忆的经历。

## Requirements

### Requirement: 按需保留形成记忆的交互依据

系统 SHALL 为从新交互产生或修订的语义记忆和程序记忆保留足以解释其来源的消息、反馈或 checkpoint 引用；普通对话无需逐轮建立长期情景条目。

#### Scenario: 用户明确表达研究兴趣
- **WHEN** 用户说“记住，我主要研究多视图聚类”，且系统采纳该兴趣
- **THEN** 后续会话可复用该语义记忆，并可从写入记录定位提出兴趣的交互；该兴趣本身无需生成 Skill。

#### Scenario: 用户纠正讲解方法
- **WHEN** 用户在一次讲解后明确要求以后先给数字例子，再解释公式，且反馈被采纳为 Skill
- **THEN** 该 Skill 的写入记录可定位这次纠正及其上下文；后续相似问答可通过 RSI 取得此策略，实际传给生成模型的版本可核对。

#### Scenario: 无可提炼内容
- **WHEN** 用户只发送问候，当前会话也没有可提炼的偏好、研究信息或操作经验
- **THEN** 普通聊天照常完成，此轮不会新增长期情景条目、语义记忆或 Skill。
